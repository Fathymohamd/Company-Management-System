# Company Management System

**Full Stack Company Management System**

A modern full-stack web application designed to manage and organize company operations through a centralized dashboard.

**Project Status:** 🚧 Currently in Development

---

## About The Project

The Company Management System is designed to simplify daily business operations and provide an organized platform for managing company resources.

The system includes modules for managing employees, customers, products, raw materials, and orders through a centralized dashboard.

## Main Features

- Employee Management
- Customer Management
- Product Management
- Raw Materials Management
- Order Management
- CRUD Operations
- Search Functionality
- Database Integration
- Responsive Dashboard

## Application Architecture

- **Frontend:** Next.js and React.js for building the user interface.
- **State Management:** Redux Toolkit for managing application state.
- **Backend:** Node.js and Express.js for RESTful APIs.
- **Database:** MySQL for storing and managing company data.
