# 🏢 Company Management System

💻 **Full Stack Company Management System**

A modern full-stack web application designed to manage and organize company operations through a centralized dashboard.

🚧 **Project Status: Currently in Development**

---

## 📌 About The Project

The Company Management System is a web-based application built to simplify daily business operations and provide an organized way to manage company resources.

The system aims to bring different company departments together in one platform, allowing administrators to manage employees, customers, products, raw materials, and orders efficiently.

🎯 **Main Goals**
- Organize company data in one centralized system.
- Simplify daily management operations.
- Improve data accessibility and management.
- Provide a responsive and user-friendly dashboard.
- Build a scalable full-stack application.

---

## ⚡ Main Features

### 👨‍💼 Employee Management
- Add new employees.
- View employee information.
- Update employee details.
- Delete employees.
- Search employees.

### 👥 Customer Management
- Add and manage customers.
- View customer details.
- Update customer information.
- Delete customers.
- Search customers.

### 📦 Product Management
- Add new products.
- Manage product information.
- Update and delete products.
- Search and filter products.

### 🧱 Raw Materials Management
- Add and manage raw materials.
- Track material quantities.
- Set low-stock alert limits.
- Manage material prices and availability.
- Update material information.

### 🛒 Order Management
- Create and manage orders.
- Track order information.
- Manage order statuses.
- Search for orders.
- Organize customer orders.

### 📊 Dashboard
- Centralized management interface.
- Organized data presentation.
- Overview of company operations.

## 🔄 Application Architecture

The application follows a full-stack architecture:

- **Frontend:** Handles the user interface and user interactions.
- **Redux Toolkit:** Manages application state and asynchronous operations.
- **Backend:** Provides RESTful APIs and handles business logic.
- **MySQL:** Stores and manages application data.
